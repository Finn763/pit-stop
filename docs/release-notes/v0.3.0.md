# v0.3.0

## Ideas is now a phase

The read-only idea step left Report and became its own phase. The run is six phases now:

```
load → find → propose → fix → ideas → report
```

Ideas runs after the fix loop closes and before the report. It stays read-only — no edits,
no new files read, no subagent — and produces at most three candidates, each shaped

```
[idea] <capability ≤20 words> — <path:line> — probe: <≤12 words>
```

Admission needs all four of anchored / shaped / falsifiable / novel. The kill list drops
generic test, CI, logging and docs requests (a missing test is an `obs` finding), new
dependencies, contradictions with this run's fixes, and anything a NOT-doing trigger
already covers. Zero candidates is the normal case. Nothing is ever built in the run that
raises it — only your explicit go starts a new run with the idea as its named goal.

Protocol, both READMEs, SPEC section 3, the three rule files, both slash entries and the
nine adapter/package manifests all moved to six phases. SKILL.md core: 414 words.

## Consistency gate

`hooks/check-consistency.sh` joins CI: pure bash+awk (no grep/jq, the same constraint the
L2 guardrail lives under), running on all three OS. It fails when an entry point still
enumerates five phases or misses Ideas, when the `[idea]` format string drifts between
`ideas.md` and the report template, or when SKILL.md passes 500 words. Release notes,
CHANGELOG and examples stay exempt as history.
