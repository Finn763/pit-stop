## 「想点子」升为独立阶段

只读的 idea 步骤从 Report 里搬出来，成为独立阶段。现在跑六个阶段：

```
装载 → 找缺点 → 给建议 → 执行 → 想点子 → 汇报
```

想点子跑在修→查循环收口之后、汇报之前。仍然只读——不改文件、不读新文件、不派子代理——
最多产出 3 条候选，格式：

```
[idea] <能力 ≤20 词> — <路径:行号> — probe: <≤12 词>
```

四条准入（锚定/成形/可证伪/新颖）全过才留。杀单：泛泛的"加测试/CI/日志/文档"（缺测试是
`obs` finding）、提新依赖、与本轮修复矛盾、NOT-doing 已覆盖的。零条是常态。本轮绝不实施——
只有你明确说 go，才会开一轮以该 idea 为命名目标的新 run。

协议、两份 README、SPEC 第 3 节、三个规则文件、两个 slash 入口、九个适配/包 manifest 全部
同步为六阶段。SKILL.md 主体 414 词。

## 一致性门

`hooks/check-consistency.sh` 进 CI：纯 bash+awk（无 grep/jq 依赖，与 L2 护栏同一约束），
三 OS 都跑。以下情况直接失败：某入口还写着五阶段或漏掉「想点子」、`[idea]` 格式串在
`ideas.md` 与报告模板之间漂移、SKILL.md 超过 500 词。发布历史、CHANGELOG、examples 作为
历史记录豁免。
