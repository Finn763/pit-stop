# v0.1.0

[English →](v0.1.0-en.md)

首个可用版本：跨端通用 Skill，一句话跑完项目改进闭环。

## 含什么

- `skills/pit-stop/SKILL.md`（358 词核心）+ 三份细节 + 报告模板
- 五阶段：装载 → 找缺点（路径行号证据+三档徽章）→ 建议 → 执行（修查循环，最多 3 轮）→ 汇报（已验证/未验证/待定）
- 三层护栏：文档禁令 + hook 机械拦截 + 推送前敏感词终扫；推送默认不动手
- 多端适配：Claude / Codex / OpenCode / Hermes / Cursor / Windsurf
- 运行环架构图（静态 SVG + 交互版）

## 安装

```bash
cp -r skills/pit-stop ~/.agents/skills/
```
