# v0.1.0

First usable release: a cross-runtime skill that runs a full project-improvement
loop from one instruction.

## What's in

- `skills/pit-stop/SKILL.md` (358-word core) + three references + report template
- Five phases: load → find (path:line evidence + strength badges) → propose →
  fix (review loop, max 3 rounds) → report (verified/unverified/remaining)
- Three-layer guardrails: banned list + hook enforcement + pre-push secrets sweep;
  push never automatic
- Adapters: Claude / Codex / OpenCode / Hermes / Cursor / Windsurf
- Run-loop architecture diagram (static SVG + interactive version)

## Install

```bash
cp -r skills/pit-stop ~/.agents/skills/
```
