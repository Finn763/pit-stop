## 护栏增强（经独立对抗审查）

- **安全扫描清单**：`security` 标签从一句话扩展为 8 类固定检查项——XSS、注入
  (SQL/NoSQL/command)、SSRF、路径穿越、越权/缺租户检查、源码/日志中的硬编码秘密、
  不安全反序列化、竞态 (TOCTOU)。秘密只做模式检测，永不提取值，`.env` 类文件遵护栏 L1。
- **失败尝试记账**：修失败回滚的方案进 attempts ledger，同一死路不试第二遍。
- **保持行为 4 问**：行为保持型修复（`delete`/`shrink`/`stdlib`/`native`/`yagni`）动手前
  自检——输出一致？错误行为一致？副作用与顺序一致？测试不改仍过？任一否 = 行为变更
  不是清理。bug/security/perf 修复豁免（行为改变本身就是修复）。

## 结构：阶段 references 拆分

`references/phases.md` 拆为四个阶段文件，按功能调试：

- `references/audit.md` — Load + Find + Propose（检查）
- `references/fix.md` — 修复规则（ledger + 4 问）
- `references/review.md` — 对抗审查循环 + 停止条件
- `references/report.md` — 报告规则

SKILL.md 主体 302 词，仍远低于 500 词上限；内容零改动，纯结构拆分。
